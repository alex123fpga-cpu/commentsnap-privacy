CommentSnap Privacy Policy

Last updated: August 30, 2026

CommentSnap is a Chrome extension that lets users turn visible YouTube comments into clean PNG images.

Information processed

When a user clicks the CommentSnap button on a YouTube comment, the extension may process information already visible on that page, including:

  • comment author or username;
  • published time;
  • comment text; and
  • visible like count.

How information is used

This information is used only to create the PNG image requested by the user. Processing happens locally in the user's browser.

Data collection and sharing

CommentSnap does not:

  • transmit comment data to a developer-controlled server;
  • store comment data remotely;
  • sell or share user data;
  • use analytics or advertising trackers;
  • use advertising identifiers;
  • use external AI services or APIs; or
  • require a user account.

Permissions and website access

CommentSnap runs only on https://www.youtube.com/* so it can detect visible comments, add the CommentSnap button, and generate the requested image.

Data retention

CommentSnap does not retain the processed YouTube comment data. The generated PNG is downloaded locally by the user's browser at the user's request.

Chrome Web Store Limited Use

CommentSnap's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Third-party services

CommentSnap is designed to work on YouTube but is not affiliated with, endorsed by, or sponsored by YouTube or Google.

Changes to this policy

If CommentSnap's data practices change in a future version, this policy will be updated before those changes are released.
